# Dataset

The source CSV `DataCoSupplyChainDataset.csv` is approximately 95 MB and has not been added to this new repository. The original copy remains in [the source project](https://github.com/Unretur/ml-journey/tree/main/Projects/SupplyGuard/data). For local training, copy the CSV into this folder as `DataCoSupplyChainDataset.csv`. The `.gitignore` excludes CSV files from commits to avoid tracking a large dataset by default.
